# `strata.naive_bayes`

GaussianNB for continuous features with adaptive variance smoothing, and MultinomialNB for discrete count data with dense and sparse CSR matrix acceleration.

---

## Structs & Classes

| Struct | Description |
| :--- | :--- |
| [`GaussianNB`](GaussianNB.md) | Gaussian Naive Bayes classifier for continuous feature modeling. |
| [`MultinomialNB`](MultinomialNB.md) | Multinomial Naive Bayes classifier for multinomially distributed count data. |

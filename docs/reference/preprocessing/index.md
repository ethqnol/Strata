# `strata.preprocessing`

StandardScaler, MinMaxScaler, RobustScaler, Normalizer, Binarizer, OneHotEncoder, OrdinalEncoder, LabelEncoder, SimpleImputer, and PolynomialFeatures with streaming SIMD statistics.

---

## Structs & Classes

| Struct | Description |
| :--- | :--- |
| [`StandardScaler`](StandardScaler.md) | Standardize features by removing the mean and scaling to unit variance. |
| [`MinMaxScaler`](MinMaxScaler.md) | Transform features by scaling each feature to a specified range. |
| [`RobustScaler`](RobustScaler.md) | Scale features using statistics that are robust to outliers. |
| [`Normalizer`](Normalizer.md) | Normalize samples individually to unit norm. |
| [`Binarizer`](Binarizer.md) | Binarize feature values according to a threshold. |
| [`OneHotEncoder`](OneHotEncoder.md) | Encode categorical features as a one-hot numeric array. |
| [`OrdinalEncoder`](OrdinalEncoder.md) | Encode categorical features as an integer array. |
| [`LabelEncoder`](LabelEncoder.md) | Encode target labels with value between 0 and n_classes-1. |
| [`SimpleImputer`](SimpleImputer.md) | Univariate imputer for completing missing values with simple statistics. |
| [`PolynomialFeatures`](PolynomialFeatures.md) | Generate polynomial and interaction features. |

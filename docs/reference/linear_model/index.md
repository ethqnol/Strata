# `strata.linear_model`

LinearRegression via OLS SVD, Ridge Regression via L2 regularization, and LogisticRegression with L-BFGS and SGD optimizers.

---

| Struct | Description |

| [`Lasso`](Lasso.md) | Lasso linear model with L1 regularization. |
| [`ElasticNet`](ElasticNet.md) | Linear regression with combined L1 and L2 regularization (ElasticNet). |

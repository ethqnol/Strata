# `strata.ensemble`

Random Forest Regressors/Classifiers with bootstrap aggregation, and Histogram-based Gradient Tree Boosting (HistGradientBoostingRegressor & HistGradientBoostingClassifier) with fast binning and regularized leaf steps.
